# NixOS configuration

NixOS + Home Manager configuration.

## Hosts

| Host | Machine | Rebuild |
| --- | --- | --- |
| `test-vm` | QEMU/KVM VM in virt-manager | `sudo nixos-rebuild switch --flake .#test-vm` |
| `usb` | External USB SSD booted on the laptop, see [docs/install-usb.md](docs/install-usb.md) | `sudo nixos-rebuild switch --flake .#usb` |
| `laptop` | Laptop internal NVMe, encrypted with a separate `/home`, see [docs/install-laptop.md](docs/install-laptop.md) | `sudo nixos-rebuild switch --flake .#laptop` |

Shared settings live in `modules/` and `home/mael/`; each `hosts/<name>/`
only holds boot, hardware and screen settings.

## Hyprland

This configuration targets current Hyprland (0.55+) and uses its Lua
configuration format through Home Manager.

The generated file is:

    ~/.config/hypr/hyprland.lua

The old `hyprland.conf` format is intentionally not used.

## VM

Before the first rebuild, make sure the repository contains the hardware
configuration generated by this VM:

```bash
cp /etc/nixos/hardware-configuration.nix hosts/test-vm/
```

Then:

```bash
nix flake check
sudo nixos-rebuild switch --flake .#test-vm
```

Reboot afterwards:

```bash
sudo reboot
```
