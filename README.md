# NixOS configuration

NixOS + Home Manager configuration for the QEMU/KVM test VM.

## Hyprland

This configuration targets current Hyprland (0.55+) and uses its Lua
configuration format through Home Manager.

The generated file is:

    ~/.config/hypr/hyprland.lua

The old `hyprland.conf` format is intentionally not used.

## VM

Before the first rebuild, make sure the repository contains the hardware
configuration generated by this VM:

```bash
cp /etc/nixos/hardware-configuration.nix hosts/test-vm/
```

Then:

```bash
nix flake check
sudo nixos-rebuild switch --flake .#test-vm
```

Reboot afterwards:

```bash
sudo reboot
```
